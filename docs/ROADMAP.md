# Local-business template roadmap

## Premium presentation
- Use client-owned photography for hero, services and gallery before launch.
- Keep demo imagery clearly labelled as demo material; never present it as client work.
- Preserve the dark/gold editorial visual language and mobile-first layout.

## Lead capture
- Enquiry form is present and configuration-driven.
- Connect form submission to a real email/CRM provider before production.
- Add spam protection, server-side validation and consent/privacy handling.

## Booking
- Keep Booking as a first-class enquiry type.
- Add a configurable booking provider URL or API adapter.
- Support availability, preferred date/time, confirmation and cancellation flows.
- Do not claim a booking is confirmed until a real provider confirms it.

## Quotes
- Support quote requests with service, property details, message and optional photos.
- Add a business-side quote status workflow: new, reviewing, quoted, accepted, declined.

## Reviews
- Add a configurable genuine-review source/provider.
- Never generate or fabricate customer reviews.
- Allow businesses to feature verified reviews and link back to the source.

## Client production
- Business configuration should control branding, contact details, services, copy, media, booking and integrations.
- Each customer should be deployable from this template without changing the core architecture.
